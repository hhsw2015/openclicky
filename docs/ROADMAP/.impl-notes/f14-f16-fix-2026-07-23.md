## F14 fixes

### F14-1 (HIGH) AnnotationStash.consume notification (unconditional)
- **File**: `Capture/AnnotationStash.swift:182-199`
- **Everywhere**: `AnnotationStash.cs:219-233`. Guard is `if (matched.IsDefaultOrEmpty) return;` then `Changed?.Invoke();` unconditionally (line 232). Fires whenever the input batch is non-empty, regardless of whether any items actually matched.
- **Fix**: drop the `removedAny` gate. Post the notification when `items.isEmpty == false`.
- **Test fallout**: `AnnotationStashTests.test_consume_isSilentWhenNothingMatches` (line 221-235) currently asserts `fired == 0` on a non-matching non-empty batch. That test encodes the buggy behavior — flip it to expect `fired == 1` and rename to `test_consume_firesEven_whenNothingMatches`.

### F14-2 (MEDIUM) AnnotationStash removeItem + remove(at:)
- **File**: `Capture/AnnotationStash.swift`
- **Everywhere**: `AnnotationStash.cs:179-193` (`RemoveItem`) and `195-209` (`Remove(int)`), each returning `bool` and posting `Changed` when they removed.
- **Fix**: add two methods:
  - `removeItem(_ item: AnnotationItem) -> Bool` — value equality since `AnnotationItem` is a struct in Swift; comment explains the C# `ReferenceEquals` divergence.
  - `remove(at index: Int) -> Bool` — bounds-checked after prune.
- Both prune expired first, then match; fire outside the lock.

### F14-3 (MEDIUM) WhiteboardStash.clearWithEvent gate on regions only
- **File**: `Capture/WhiteboardStash.swift:193-206`
- **Everywhere**: `WhiteboardStash.cs:217-227`. `fire = _current is not null;` — gated on the regions slot only. `_imageBytesById` is a side effect the caller might have loaded via a previous `set()` even without regions.

### F14-4 (LOW) WhiteboardStash silent clear()

## F16 fixes

### F16-1 (HIGH) memory_snapshot semantic
- **Files**: `Memory/MemoryStore.swift`, `Memory/OpenClickyMemoryTools.swift`.
- **Everywhere**: `MemoryTools.cs:162-175` + `MemoryStore.cs:197-215`. `memory_snapshot(site, cmd, content)` writes `content` to `sites/<domain>/fixtures/<cmd>-<iso>.json` and rotates by keeping the 5 newest.
- **Constraint**: bridge (`OpenClickyExternalControlBridge.swift`) is not touchable; it already calls `memorySnapshot()` (no args) to return `MemorySnapshot`. Renaming the existing method would break the bridge build.
- **Fix (compat-preserving)**:
  - Add `MemoryStore.writeSnapshot(cmd:, content:, keepLast: 5) throws -> URL`. Writes to `<storeDir>/snapshots/<cmd>-<yyyymmddTHHmmssZ>.json`, prunes to `keepLast` newest per cmd. ISO formatting matches Everywhere's `yyyyMMddTHHmmssZ` (`MemoryStore.cs:202`).
  - Add `OpenClickyMemoryTools.memorySnapshotWrite(cmd:, content:) throws -> String` returning the path (Everywhere returns `{ok:true}` but the path is more useful for parity tests).
  - Keep `memorySnapshot()` no-arg dump for bridge compat. Update its doc-comment to explicitly note the Everywhere wire-name inversion and point to `memorySnapshotWrite`.

### F16-2 (MEDIUM) memory_freshness enum
- **Files**: `Memory/MemoryStore.swift`, `Types/CaptureTypes.swift`.
- **Everywhere**: `Freshness.cs:11-17` — `age < 30d = fresh`, `< 90d = stale`, else `cold`. `MemoryStore.Freshness` returns `"cold"` when `verifiedAt == 0` (`MemoryStore.cs:191`).
- **Fix**: extend `MemoryFreshnessInfo` with a `freshness: String` field alongside existing numeric fields. Compute the string in `MemoryStore.freshness()`. Preserves current downstream callers.

### F16-3 (LOW) remove dead MemoryEntry
