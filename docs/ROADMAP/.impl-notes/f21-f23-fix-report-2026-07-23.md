### Change 1 — `OpenClickyKnownAppRule` value type + `OpenClickyKnownAppResolver`

**Before**: `formatForHook` hard-coded `let discoveryUrl: String? = nil; let statePath: String? = nil` (former `OpenClickyContextSnapshotPayload.swift:285-286`). The `else if let discovery = discoveryUrl, let state = statePath` branch (former line 301) was unreachable dead code.

**After**: `OpenClickyContextSnapshotPayload.swift:206-303` (new region).

- New `OpenClickyKnownAppRule` struct mirrors Everywhere's `McpServerSettings.KnownApp` (`McpServerSettings.cs:15-19`). Value type with no AppKit / UserDefaults dependency so the pure serialiser stays test-friendly.
- `OpenClickyKnownAppResolver.resolveDiscoveryUrl(appTitle:knownApps:) -> (discoverUrl: String, statePath: String)?` ports `ContextStashWriter.cs:756-791`:
  - Iterates rules in registration order (first-match wins).
  - Skips blank pattern / blank URL entries (parity with `ContextStashWriter.cs:763-764`).
  - Rejects non-http(s) discover URLs via `URL(string:)` + scheme check (parity with `ContextStashWriter.cs:768-769`).
  - Compiles each `titlePattern` with `NSRegularExpression(pattern:options:.caseInsensitive)`; invalid syntax is a silent skip (parity with the `ArgumentException` branch at `ContextStashWriter.cs:785-788`).
  - ReDoS mitigation: input title capped at 512 chars before match (`redosInputCap`). Documented divergence from Everywhere's 100 ms `RegexMatchTimeoutException` (Swift `NSRegularExpression` has no per-match timeout). Header comment on the resolver enum spells this out; new unit test `test_resolveDiscoveryUrl_pathologicalPatternCompletesFast` drives `^(a+)+$` against 500 'a's + 'b' and asserts <2 s completion.
- `OpenClickyKnownAppResolver.toStatePath(_ discoverUrl: String) -> String` ports `ContextStashWriter.cs:743-751`:
  - `/agent-skills` suffix → replace with `/agent-state` (case-insensitive).
  - `/xlb-perception` suffix → replace with `/agent-state` (case-insensitive).
  - Otherwise return input unchanged.

### Change 4 — `classifyByScreen` implementation

**Before**: `OpenClickyWhiteboardOverlayWindow.swift:411-418` returned `[]` unconditionally. The overlay preview renderer at `:216-219` + draw code at `:140-161` was dead.

**After**: `OpenClickyWhiteboardOverlayWindow.swift:412-497`.

- `classifyByScreen(strokes:)` (instance method, changed from static) converts session strokes to `OpenClickyWhiteboardStroke` values, runs `OpenClickyWhiteboardStrokeClassifier.classify` (which already ports `WhiteboardParser.ParseGrouped` @ `WhiteboardParser.cs:39-55` byte-for-byte per the F23 review), then buckets each resulting `(kind, boundingBox)` pair into the overlay view whose panel contains the bbox centre.
- New helper `viewForQuartzRect(_ rect:)` hit-tests the rect centre against each panel's Cocoa-space frame (converting from Quartz global). Falls back to the first view when no panel covers the rect (guards against degenerate zero-area rects from Unknown gestures).
- New static helper `quartzRectToViewLocal(rect:view:)` flips the Quartz global rect (top-left origin) back to view-local Cocoa (bottom-left origin) so `showClassifiedOverlay` draws at the correct position.
- Call site at `:315` updated from `Self.classifyByScreen` to `self.classifyByScreen` (now instance method).

### Change 5 — Auto captureAsync after whiteboard commit

**Before**: `OpenClickyWhiteboardOverlayWindow.swift.processAndStash(...)` ended at `WhiteboardStash.shared.set(...)`. Users had to press SnapshotContext manually to ship whiteboard regions to the agent envelope (see F23 review Issue 6).

**After**: `OpenClickyWhiteboardOverlayWindow.swift:597-609`. After the WhiteboardStash write, when at least one region survived classification (guards against all-degenerate-stroke sessions overwriting an existing pin-only stash):

```swift
if !regions.isEmpty {
    await OpenClickyContextStashWriter.shared.captureAsync()
}
```

Matches Everywhere's `_contextWriter.CaptureAsync()` call at `WhiteboardHotkeyInitializer.cs:735`. Method `processAndStash` gained `@MainActor` annotation (`:503-504`) so the writer's main-actor isolation is satisfied without a `MainActor.run` hop; the surrounding `Task { @MainActor in ... }` at `:332` already provided main-actor context but static async funcs don't inherit isolation.

No new "trigger" enum needed — the existing `captureAsync()` entry point on the writer already handles the "auto capture, don't activate the agent app" path correctly (`OpenClickyContextStashWriter.swift:80-82` calls `captureCoreAsync(drainAnnotations: true, ...)`; while `drainAnnotations` is `true`, this is fine for whiteboard auto-fire because the writer's peek of `WhiteboardStash` already includes the just-written regions).
