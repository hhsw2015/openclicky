## Files to create

1. `cursor-buddy/OpenClickyContextHotkeys.swift`
   - `OpenClickyContextHotkeyAction` enum (5 actions: snapshotContext,
     clearContextStash, agentPickElement, whiteboard, linkRect)
   - `OpenClickyHotkeyBinding` struct (keyCode: UInt16, modifiers: UInt64,
     enabled: Bool) with UserDefaults codable JSON persistence
   - `OpenClickyContextHotkeys` class (ObservableObject): CGEventTap manager
     mirroring GlobalPushToTalkShortcutMonitor. Reads `.keyDown` +
     `.flagsChanged`, compares against active bindings, fires actions on
     main queue. RepeatSuppressionMs=1500 per action, ModifierReleaseDelay
     Ms=180 before capture (i.e. `DispatchQueue.main.asyncAfter(deadline:
     .now() + 0.18)` before actually running the action so the modifier
     keys are released).

   - Auto text-selection toggle key
     `openclicky.contextAwareness.autoSelectionObserverEnabled` default
     false.
   - Helper `keyLabel(for binding)` — describes "⌘⇧K" style.

## Behaviour

- All 5 bindings absent from UserDefaults on fresh install → hotkey tap
  has zero registered chords → no CGEvent taps active (we still install
  one shared tap for efficiency but with an early-out when no bindings
  enabled).
- Repeat suppression: per-action `lastFireDate`, skip if `< 1500ms`.
- Modifier release delay: capture keyDown event, dispatch action after
  `+0.18s` on main queue so the modifier-still-pressed state doesn't
  contaminate downstream captures.
- Master toggle off → shared tap runs but immediately returns from
  callback without firing actions.

## Action mapping

1. SnapshotContext → `Task { await OpenClickyContextStashWriter().captureAsync() }`
2. ClearContextStash → `OpenClickyContextStashWriter().clearStash()` +
   `PickStash.shared.clearWithEvent()` +
   `AnnotationStash.shared.clearWithEvent()` +
   `WhiteboardStash.shared.clearWithEvent()`
3. AgentPickElement → `NSEvent.mouseLocation` → convert to CGPoint →
   `AXUIElementCopyElementAtPosition(AXUIElementCreateSystemWide(), x, y,
   &el)` → serialise attributes → `PickStash.shared.set(picked)`
4. Whiteboard → stub log + `WhiteboardStash.shared.set(regions: [],
   imageBytesById: [:])` (empty regions leave `hasPending=false` per
   WhiteboardStash contract; that's the "wired but no drawing yet"
   state). Log "openclicky.hotkey.whiteboard.pressed" so we can grep.
5. LinkRect → stub log only ("openclicky.hotkey.linkrect.pressed"). Full
   drag rect UI is Phase 7.1.
