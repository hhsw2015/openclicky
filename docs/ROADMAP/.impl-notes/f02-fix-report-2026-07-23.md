## Fixes applied

### HIGH — SemanticExtractor.readBool now accepts CFNumber
- File: `Packages/OpenClickyContextService/Sources/OpenClickyContextService/Capture/SemanticExtractor.swift`
- Before: L552-558 only checked `CFBooleanGetTypeID`, returning `nil` for CFNumber-backed bool values (SwiftUI / Electron / some AppKit apps).
- After: L560-582 now checks CFBoolean first, then falls back to CFNumber and reads as `Int != 0`. Matches Everywhere's `NSNumber.BoolValue` semantic in `AXUIElement.cs:229-241` and mirrors the already-correct `FocusedElementCapture.readBool` at L386-403.

### MEDIUM 1 — AXUIElementSetMessagingTimeout bootstrap
- File: `Packages/OpenClickyContextService/Sources/OpenClickyContextService/Capture/AXQuirksInstaller.swift`
- Everywhere reference: `AXUIElement.cs:471-475` static ctor sets 1s timeout on SystemWide handle ONCE globally.
- Added: `axBootstrap` `static let Void` (Swift dispatch-once idiom) that calls `AXUIElementCreateSystemWide()` and `AXUIElementSetMessagingTimeout(_, 1.0)`. Exposed as `ensureAXBootstrap()`.
- Wired into: `installIfNeeded(pid:)` (installer entry) plus `SemanticExtractor.focusedPath/focused/selected` and `FocusedElementCapture.capture`. Idempotent — subsequent calls are single atomic load.

### MEDIUM 2 — State emit order
- Files:
  - `Capture/SemanticExtractor.swift` — `statesList` (PascalCase output).
  - `Capture/FocusedElementCapture.swift` — `readStates` (lowercase output).
- Before: hand-coded order (Disabled/Selected/Expanded/Focused/Offscreen/Password/Checked).
- After: emission follows `Enum.GetValues<VisualElementStates>()` numeric order per `IVisualElement.cs:60-84`:
  - Offscreen (1<<0)
  - Disabled  (1<<1)
  - Focused   (1<<2)
  - Selected  (1<<3)
  - Password  (1<<5)
  - Expanded  (1<<6)
  - Checked   (1<<13)

### MEDIUM 3 — kMaxPathDepth = 64
- File: `Capture/SemanticExtractor.swift`
- Before: `kMaxPathDepth = 32` (L75), header comment claimed Everywhere caps at 12.
- After: `kMaxPathDepth = 64` (L74), 1:1 with `UpstreamConstants.AccessibilityTreeMaxDepth = 64` at `UpstreamConstants.cs:11`. Header comment corrected. Test bound updated to `<= 64`.

### MEDIUM 4 — SemanticNode omits nil optionals in JSON
- File: `Types/CaptureTypes.swift`
- Before: default `Codable` synthesis emitted explicit `null` for `text`, `states`, `available_actions`.
- After: added explicit `encode(to:)` using `encodeIfPresent` (plus paired `init(from:)` so decode is preserved). Wire shape matches Everywhere's `SemanticItem.cs` `[JsonIgnore(Condition = WhenWritingNull)]`.
- SemanticFocusPath has no optional fields, so no null-write concern.

### MEDIUM 5 — readValueString split
- File: `Capture/FocusedElementCapture.swift`
- Before: single `readValueString(from:role:)` at L214-243 unconditionally applied the AXCheckBox 0→false / else→true transform. Called from both the Name cascade (wrong — a checkbox labelled "0" or "1" would be rewritten) and the user-visible `value` field.
- After: split into two helpers:
  - `readValueRaw(from:)` — no transform, matches Everywhere's `GetAttribute<NSObject>(Value)?.ToString()` calls in `Name` (`AXUIElement.cs:281, 296, 355`).
  - `readValueTransformed(from:role:)` — with AXCheckBox transform, matches `GetText` (`AXUIElement.cs:549-556`).
- Callers rewired:
  - `readName` L138 label-role value → `readValueRaw`.
  - `readName` L143 titleElement value → `readValueRaw`.
  - `firstChildStaticTextValue` L197 child value → `readValueRaw`.
  - `capture` L98 wire-value field → `readValueTransformed` (unchanged behavior for the wire).
