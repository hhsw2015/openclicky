### Reused package APIs (from `import OpenClickyContextService`)
- `FrontmostAppCapture.capture() -> FrontmostAppInfo?` — sync, main-thread safe.
- `FocusedWindowCapture.capture(processId: Int32) -> FocusedWindowInfo?` — sync.
- `BrowserURLCapture.capture(processId: Int32?) async -> BrowserURLInfo?`
- `FinderSelectionCapture.capture() async -> FinderSelectionInfo?` (AppleScript, off-main).
- `SelectionCache.shared` — writable cache with `.getFresh()` / `.store(text:appKey:)`.
- `SelectedTextCapture.capture(cache:)` — NOT USED: it can escalate to Cmd-C. We inline a strategy-1-only AX read to preserve "no side effects" preflight guarantee.

### System prompt injection strategy
- The `currentVoiceResponseSystemPrompt()` prompt lives in `CompanionManager.swift`, which is OUTSIDE the allowed edit surface for this step.
- The proxy ignores `systemPromptForBody` anyway, so mutating that prompt would be a no-op.
- Solution: place BOTH the `[openclicky-context]…[/openclicky-context]` block AND an `[openclicky-directives]…[/openclicky-directives]` block (containing the context-awareness explainer and the `[ROUTE]` JSON contract) at the START of the augmented `query`. The user's raw transcript follows.
- Gated by `UserDefaults.standard.object(forKey: "openclicky.contextAwarenessEnabled") as? Bool ?? true`. When false, query goes through untouched (old behaviour).

### Route JSON parse
- Regex: `\[ROUTE\]\s*(\{[^\n]*\})`.
- Use `NSRegularExpression`, keep the LAST match (Fable is instructed to emit exactly one line at end; last-wins hardens against accidental duplicates).
- Decode with `JSONDecoder` into `RouteParseResult { kind, projectRef, slug, workdir, confidence }`.
- Log via `HeyClickyLog.log("openclicky.route_parsed", …)` on hit, `openclicky.route_missing` otherwise. NO DISPATCH.

## Doc reconciliation
`docs/ROADMAP/02_LAYER_1_INTENT_ROUTER.md` §"Prefetched context 组 1" lists exactly:
- FrontmostApp (bundle_id, name) — 1 ms
- FocusedWindow.title — 5 ms
- BrowserURL — only if frontmost is browser, 5 ms
- FinderSelection (currentFolder + first 3 filenames) — 30 ms
- SelectedText (AX strat 1 only, no Cmd-C) — 5 ms
- ClipboardPreview — optional, default skip

The implementation matches items 1-5 exactly and skips the optional ClipboardPreview per the roadmap default. No divergence.

The example block format in §"Prepend query as" (lines 192-202) matches our `formatPreflightBlock`:
```
[openclicky-context]
frontmost_app: com.apple.Safari (name=Safari)
window_title: "GitHub - openclicky"
url: https://github.com/...
selected_folder: null
selected_text: "func foo() { return 42 }"
[/openclicky-context]
```
Divergence note: doc uses `name=Safari`; we emit `(Safari)` shorthand for token economy. Semantics preserved.

The `[ROUTE]` JSON shape from §"CLASSIFICATION RULES" lines 62-66:
```
[ROUTE] {"kind":"chat"|"short_task"|"long_task_new"|"long_task_existing"|"ambiguous",
"project_ref":null|string, "slug":null|string, "workdir":null|string,
"confidence":0.0-1.0}
```
`RouteParseResult` mirrors these five fields verbatim.
