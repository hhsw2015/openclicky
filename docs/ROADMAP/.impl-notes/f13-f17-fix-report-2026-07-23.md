## F13 InputSimulator fixes

### F13-1 (HIGH) - Modifier keyup posts before flag clear

- File: `InputSimulator.swift`
- Old: keyup loop at lines 181-190 called `activeFlags.remove(flag)` FIRST, then posted the keyup with the flag already gone.
- New (`InputSimulator.swift` around lines 181-196): keyup event is posted first with the modifier flag still in `activeFlags`, then the flag is cleared. If `CGEvent(...)` returns nil we still clear the flag and continue.
- Everywhere reference: `MacInputSimulator.cs:170-178` — `CGEventSetFlags(ev, activeFlags); PostEvent(ev, targetPid); ...; activeFlags &= ~flag;` runs the clear AFTER the post.

### F13-2 (MEDIUM) - `typeText` default delay 30 -> 20

- File: `InputSimulator.swift`
- Old signature: `typeText(_ text: String, delayMs: Int = 30)`
- New signature: `typeText(_ text: String, delayMs: Int = 20)`
- Callers checked: `OpenClickyAppActivator.swift:197` never passes `delayMs:`, tests always pass explicit `delayMs: 0`. Safe to change default.
- Everywhere reference: `MacInputSimulator.cs:96` and `MacInputSimulator.cs:105` both `Thread.Sleep(20);`

### F13-3 (MEDIUM) - `pressKey` throws on main-key event creation failure

- File: `InputSimulator.swift`
- Old: main-key CGEvent creation guarded with `if let` and silently dropped both events on nil.
- New:
  - Added `KeyError.eventCreationFailed(key: String)` case with a `description` that reads `failed to create key event for '<name>'`.
  - Main-key `guard let down = CGEvent(...) else { releaseHeldModifiers(...); throw ... }` (and same for `up`).
  - New private helper `releaseHeldModifiers(_:_:)` posts explicit modifier keyups so the user is not left with a stuck Shift/Cmd/etc.
- Everywhere reference: `MacInputSimulator.cs:154-158` throws `InvalidOperationException("Failed to create key event.")` in the equivalent branch.
- Existing caller `cursor-buddy/OpenClickyAppActivator.swift:209` already uses `try InputSimulator.pressKey("Return")`, so the surface stays compatible.

### F13-4 (LOW) - `graphemeChunks` off-by-one on cap boundary

- File: `InputSimulator.swift`
- Old: `if clusterUnits >= maxUnits { ... }` at line 312.
- New: `if clusterUnits > maxUnits { ... }` at the same location.
- Everywhere reference: `MacInputSimulator.cs:102` `(grapheme.Length > Max && sb.Length == 0)` — strictly greater than.

### F13-5 (LOW) - Add `scroll(at:direction:pages:)` overload

- File: `InputSimulator.swift`
- Added: `enum ScrollDirection: String, Sendable { case up, down, left, right }`
- Added: `static func scroll(at:direction:pages:)` that computes delta via a new `internal static func computeScrollDelta(pages:) -> Int32`.
- `computeScrollDelta` mirrors Everywhere `MacInputSimulator.cs:214-219`: `round(12 * pages, MidpointRounding.AwayFromZero)`, clamped to `[1, Int32.max]`.
- Raw `scroll(at:dx:dy:)` untouched.

### F13-6 (LOW) - Chord parser strips inner whitespace

- File: `InputSimulator.swift`
- Old: per-token `.trimmingCharacters(in: .whitespaces)` only stripped outer whitespace.
- New: helper `normaliseChordToken(_:)` lowercases and drops every whitespace scalar; both branches of `splitChord` (fused and separate) route through it.
- Everywhere reference: `MacInputSimulator.cs:120` `t.ToLowerInvariant().Replace(" ", string.Empty)` — strips ALL spaces including internal.

## F17 Meta+BM25 fixes

### F17-1 (HIGH) - G7 mutation-verb guard uses word-boundary regex

- File: `OpenClickyMetaTools.swift`
- Old (lines 434-444): four `evidenceLine.uppercased().contains(verb)` checks — false-flagged "POSTAL", "OUTPUT", "PATCHY", "REPUTATIONAL", "DELETES".
- New:
  - Added file-level constant `openClickyMetaMutationVerbRegex` compiled once from `\b(POST|PUT|DELETE|PATCH)\b`.
  - G7 check now uses `firstMatch(in:options:range:)` against the uppercased evidence line.
- Everywhere reference: `GateTools.cs:47` and `MutationGuard.cs:16-18` — same pattern, same word-boundary semantics.

### F17-2 (MEDIUM) - BM25 duplicate register no longer inflates N

- File: `OpenClickyMetaTools.swift`
- Old: `OpenClickyBM25Index.add(_:)` always appended a fresh `Doc`. When `OpenClickyMetaToolRegistry.register` was called twice for the same tool name, the `descriptors` map overwrote but the index appended, so `N` (`docs.count`) inflated.
- New:
  - Added `indexByName: [String: Int]` to the index.
  - `add(_:)` now overwrites in place when the name already exists: strips old postings for that `idx`, replaces the `Doc`, and re-inserts new-token postings.
  - Added `internal var documentCount: Int { docs.count }` on the index.
  - Added `internal var bm25DocumentCount: Int` on the registry (test-only accessor) so tests can prove `N == 1` after N duplicate registrations.
