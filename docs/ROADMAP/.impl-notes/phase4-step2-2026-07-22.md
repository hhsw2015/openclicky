## Plan

1. Create `cursor-buddy/OpenClickyRouteDispatcher.swift`
   - `@MainActor final class RouteDispatcher`
   - `.shared` singleton, `weak var companionManager: CompanionManager?`
   - `dispatch(_:userTranscript:preflight:)` — routes `short_task`/`long_task_*` to codex spawn; `chat`/`ambiguous` = no-op.
   - `classifyFallback(userTranscript:preflight:) async -> RouteParseResult` — uses `WorkdirProbe` + `ProjectRegistry` only; no keyword lists.
   - `composeAgentPrompt(...)` — prepend scene context + intent hint before the raw transcript.
   - `sanitizedSlug(from:)` — regex-based, no keyword table.

2. Modify `HeyClickyChatToolCallClient.swift`
   - Hoist `preflightSnapshot: FablePreflightContext?` to outer scope (nil when context awareness disabled).
   - After `parseRouteJSON` success -> `RouteDispatcher.shared.dispatch(...)`.
   - After parse miss + preflight available -> run `classifyFallback`; if kind != "chat" -> dispatch. Otherwise no-op (safe default; TTS already played dialog reply).

3. Modify `CompanionManager.swift`
   - At end of `init(runtimeMode:)` (line 1778) add `RouteDispatcher.shared.companionManager = self`.
   - Extend `startVoiceAgentTaskPlan` and `startVoiceAgentTask` with `workingDirectoryOverride: String? = nil` (default -> backwards compat). Apply override after `createAndSelectNewCodexAgentSession(...)` before `submitAgentPrompt(...)`.
   - Add public bridge `dispatchRoutedAgentTask(instruction:workingDirectoryOverride:voiceContextUserTranscript:)` so `RouteDispatcher` doesn't need to reach into `private` fn.
