  - `Offscreen = 1<<0`
  - `Disabled = 1<<1`

  - `Selected = 1<<3`

- Fix: emit Offscreen → Disabled → Focused → Selected → Password → Expanded → Checked in both SemanticExtractor (PascalCase) and FocusedElementCapture (lowercase per pre-existing invariant).

### MEDIUM 5 — readValueString split
- openclicky `FocusedElementCapture.readValueString`: applies AXCheckBox transform unconditionally.
- Everywhere splits:
  - `Name` context: `GetAttribute<NSObject>(Value)?.ToString()` (no transform) — used at `AXUIElement.cs:281`, `:296`, `:355`.
  - `GetText` context: applies checkbox transform (`AXUIElement.cs:549-556`).
- Callers in openclicky:
  - `readName` L138 — Name cascade → should be no-transform.
  - `readName` L143 (titleElement value) → no-transform.
  - `firstChildStaticTextValue` L197 — child value in name cascade → no-transform.
  - `capture` L98 (`value = readValueString(...)`) → this represents the "Value" wire field. Everywhere's ValueString mapping for `AXCheckBox` in `GetText` applies the transform.
