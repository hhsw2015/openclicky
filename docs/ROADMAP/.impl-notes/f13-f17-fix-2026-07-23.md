### Issue 1 (HIGH) - Modifier keyup flag-clear order

Current (`InputSimulator.swift:181-190`):
```
for (flag, modCode) in resolvedModifiers.reversed() {
    activeFlags.remove(flag)      // <-- cleared BEFORE post
    guard let ev = CGEvent(...) else { continue }
    ev.flags = activeFlags
    ev.post(tap: .cghidEventTap)
}
```

Everywhere (`MacInputSimulator.cs:170-179`):
```
for (i = modifiers.Count - 1; i >= 0; i--) {
    (flag, mkc) = modifiers[i];
    ev = CGEventCreateKeyboardEvent(nint.Zero, mkc, false);
    ...
    CGEventSetFlags(ev, activeFlags);   // <-- posted WITH flag set
    PostEvent(ev, targetPid);
    CFRelease(ev);
    activeFlags &= ~flag;               // <-- cleared AFTER post
}
```

Fix: swap so the keyup posts with modifier flag still active, then clear afterwards.

## F17 Meta+BM25

- File: `Packages/OpenClickyContextService/Sources/OpenClickyContextService/Meta/OpenClickyMetaTools.swift`

### Issue 1 (HIGH) - G7 mutation-verb false positive

Current (`OpenClickyMetaTools.swift:434-444`):
`evidenceLine.uppercased().contains(verb)` for `["POST", "PUT", "DELETE", "PATCH"]`
False-triggers on "POSTAL", "REPUTATIONAL", "PATCHY", "OUTPUT".

Fix: use `NSRegularExpression("\\b(POST|PUT|DELETE|PATCH)\\b")`. Same set of verbs, but word-boundary anchored.

### Issue 2 (MEDIUM) - BM25 duplicate register

Currently `register` handles the `descriptors` map correctly (in-place overwrite) but the `order` array skips duplicates. However, `index.add(descriptor)` is called unconditionally, appending a fresh `Doc` on re-register. This inflates N in BM25 and skews IDF/avgLen.

Fix: give `OpenClickyBM25Index` a `docsByName: [String: Int]` map. On `add`:
- If already present: overwrite `docs[existingIdx]`, rebuild postings for that idx (subtract old tokens, add new).
- Else: append.

Simpler alternative given no external mutators expect specific indices: rebuild the whole index in the registry when a duplicate is detected. Since add is O(N) already (rolling average recompute), a rebuild on duplicate is acceptable.

Approach: add `rebuild(_ descriptors: [MetaToolDescriptor])` to BM25 index and call it from `register` when overwriting.
