### HIGH #2 — `ManualCaptureCompleted` fan-out wired

Three-part patch:

1. **Notification name** — added in `cursor-buddy/OpenClickyContextStashWriter.swift:27-40` (new `Notification.Name.openClickyManualCaptureCompleted`), citing Everywhere `ContextStashWriter.cs:49, 207, 343`.

2. **Post site A** — `cursor-buddy/OpenClickyContextStashWriter.swift` inside `captureCoreAsync`, immediately after successful atomic write when `drainAnnotations == true` (the "manual snapshot" gate Everywhere uses at `ContextStashWriter.cs:340-344`). Post is fire-and-forget on `NotificationCenter.default`.

3. **Post site B** — `cursor-buddy/OpenClickyContextStashWriter.swift` inside the `captureLinks(_:[(String, String)])` overload, immediately after successful atomic write. Mirrors Everywhere's `ContextStashWriter.cs:207` where the LinkRect direct-ship path fires the same event.

4. **Observer** — `cursor-buddy/OpenClickyAnnotationBadgeOverlay.swift` inside `start()`:
   - Added a Combine subscription on `.openClickyManualCaptureCompleted` that routes to `handleManualCaptureCompleted()`.
   - New method `handleManualCaptureCompleted()`:
     - Calls `clearAllBadges()` (tears down every NSPanel pair).
     - Drains `PickStash.shared.clearWithEvent()`.
     - Drains queued annotations via `annotationStash.consume(annotationStash.peek())`.
     - Drains `WhiteboardStash.shared.clearWithEvent()`.
     - Wipes `OpenClickyPinnedAXElementRegistry.removeAll()`.
   - New helper `clearAllBadges()` iterates `pairs` calling `tearDown()` and clears the dict.

Everywhere semantic parity: `AnnotationOverlayHost.cs:218-237` unsubscribes handlers, hides + closes both overlay panels, drops `_overlays.Clear()`. Everywhere additionally consumes the annotations *before* the writer fires the event (`ContextStashWriter.cs:204`), and the stash is single-source: dropping it upstream is enough. Our writer keeps annotations at `nil` in Phase 7 (see `OpenClickyContextStashWriter.swift:162`) so the badge overlay is the only place that owns the queue — draining it here mirrors the end-state on Everywhere.

Header comment on `OpenClickyAnnotationBadgeOverlay.swift:15-22` updated to document the new subscription.

### LOW — `observedElements` dedup

`cursor-buddy/OpenClickyAXFollower.swift` inside `installObserver()`.

- Before: `observedElements.append(target)` fired once per successful `AXObserverAddNotification`, so each target ended up in the array 4× (one per notification).
- After: track a per-target `installedForTarget` bool and only append once, guarded by `CFEqual($0, target)` to dedup by AX ref identity.

Net effect at `stop()`: `AXObserverRemoveNotification` calls drop from 4×N × 4 = 16 per target to 4 per target. The extras were harmless (`-25204 not-registered`) but noisy.
